# 🤖 Never Land | بوت إدارة سيرفرات ديسكورد متكامل + لوحة تحكم

بوت ديسكورد احترافي مبني بـ **Node.js + discord.js v14**، يجمع كل ميزات إدارة السيرفرات في مشروع واحد مفتوح المصدر،
مع **لوحة تحكم ويب عربية بالكامل** تُدار من المتصفح.

> **الموقع الرسمي:** هذا المشروع يشغّل موقعًا حقيقيًا (صفحات مُولَّدة من الخادم + واجهة API + قاعدة بيانات)،
> وليس نسخة HTML ثابتة: `/` الصفحة الرئيسية، `/dashboard` لوحة السيرفرات، `/dashboard/:id` لوحة الإعداد الكاملة،
> مع `/icon.svg` و`/manifest.webmanifest` و`/robots.txt` و`/sitemap.xml` وصفحة 404 مصمّمة.
> الاسم الظاهر في كل الصفحات يُضبط من متغيّر `SITE_NAME` (الافتراضي: **Never Land**).

> ✨ **الميزة الأقوى:** العربية أولًا. كل ردود البوت ولوحة التحكم بالعربية (مع دعم الإنجليزية)،
> وفلتر الكلمات الممنوعة يتعامل مع الكتابة العربية الشائعة (تشكيل، همزات، تاء مربوطة...).

### ➖ الخط الفاصل التلقائي (AutoLine)
خط فاصل يُرسل تلقائيًا بعد كل رسالة في قنوات محدّدة — مثالي لقنوات التقديمات.
- شكل الخط قابل للتخصيص (يدعم الإيموجيات الخارجية)
- حذف الخط السابق تلقائيًا عند وصول رسالة جديدة
- حذف الخط مع حذف رسالته + حذف تلقائي بعد مدة

### 😀 التفاعلات التلقائية (AutoReaction)
- تفاعل تلقائي بإيموجيات محدّدة على كل رسالة في قنوات محدّدة
- **تفاعل عند احتواء الرسالة على كلمة مفتاحية** (ترحيب ➜ 👋)
- دعم كامل للإيموجيات الخارجية والمتحرّكة `<a:name:id>`

### 👋 الترحيب والتفاعل — مع صورة بالأفتار
- **صورة ترحيب بالبطاقة:** بطاقة مولَّدة بـ Canvas تحتوي أفتار العضو + اسمه + رقم انضمامه + اسم السيرفر
- أو صورة الأفتار مباشرة، أو صورة مخصّصة برابط، أو بدون صورة
- خلفية قابلة للتخصيص + تدرّج لوني للبطاقة
- متغيّرات: `{user}` `{username}` `{displayName}` `{server}` `{memberCount}` `{avatar}` `{createdAt}` `{joinedAt}`
- ترحيب في الخاص • وداع • شكر الدعم (Boost) • رتب تلقائية • تتبّع من دعا مَن

### 📜 السجلات — روم خاص لكل حدث
**38 حدثًا في 9 مجموعات، وكل حدث تقدر تحطه في روم لحاله:**

- مثال: «حظر عضو» في روم · «طرد عضو» في روم ثاني · «حذف رسائل» في روم ثالث — بلا خلط
- اختصار سريع: روم واحد لكل مجموعة (أعضاء · رسائل · رتب · قنوات · صوت...) — والحدث اللي له روم خاص يتقدّم عليه
- أولوية التوجيه: **روم الحدث الخاص ← روم المجموعة ← القناة العامة (اختيارية)**
- بلا أي روم مرتبط ⇒ الحدث ما يُسجَّل (ما في لوق شامل إلزامي)
- كل هذا من لوحة التحكم (اختيار روم بجانب كل حدث) أو بالأمر `/logs eventchannel` و`/logs channels`

### 🎫 التذاكر — 4 أنواع جاهزة
**🛠️ الدعم الفني • ✅ التوثيق • 🎁 الهدايا • 📋 تقديم إدارة**

- **لوحة بنل** برسالة واحدة نظيفة — بلا فوتر وبلا رسالة تعليمات منفصلة، وإعادة النشر تشيل اللوحة القديمة تلقائيًا
- **وضعان للوحة:** أزرار (Buttons) أو قائمة منسدلة (Select)
- **دعم الإيموجيات الخارجية** في الأزرار والأنواع والرسائل `<:name:id>`
- لكل نوع: وصف، إيموجي، رسالة داخلية، ولون الزر — الكل قابل للتعديل من اللوحة أو من ديسكورد
- داخل التذكرة: 🙋 استلام • 🔒 إغلاق • 📄 أرشيف • ➕ إضافة عضو
- **أزرار التذكرة قابلة للتخصيص بالكامل:** اكتب نص كل زر، وأضف له إيموجي (عادي أو خارجي)، واختر لونه — من لوحة التحكم (مع معاينة فورية لشكل الزر) أو بالأمر `/tickets button`، و`/tickets buttons` يعرض الشكل الحالي
- إغلاق مع **أرشيف محادثة كامل** يُرسل لقناة السجلات + رسالة خاصة لصاحب التذكرة

### 📝 نظام تقديم الإدارة (Applications) — بضغطة زر
تذكرة **"تقديم إدارة"** ما تبقى روم فاضي — البوت يشتغل بدالك:

1. **يفتح نموذج (Modal) من 5 خانات** — نفس اللي طلبته بالحرف:

| # | الخانة |
|---|---|
| 1 | الاسم والعمر |
| 2 | من أي بلد أنت؟ |
| 3 | سيرفرات كنت فيها إداريًا؟ |
| 4 | هل تقدر تفتح مايك؟ |
| 5 | هل تقدر تحط شعار ورابط؟ |

2. **الإجابات تروح مباشرة لقناة مراجعة الإدارة** مع أزرار: ✅ **قبول العرض** • ❌ **رفض العرض** • 🔗 الذهاب للتذكرة.
3. **❌ رفض** ➜ يكتب المشرف السبب في نموذج صغير ➜ يوصل للمتقدّم **رسالة خاصة**: «لقد تم رفض عرضك» + السبب.
4. **✅ قبول** ➜
   - **رسالة خاصة للمتقدّم**: «🎉 لقد تم قبول عرضك» + رقم ملفه
   - **رسالة داخل التذكرة**: «لقد تم قبول عرضك» مع تنبيهه
   - **إعادة تسمية التذكرة** باسمه وترقيمها: `إدارة-001-ahmed`
   - **نقلها إلى قسم تكتات الإدارة** تلقائيًا
   - **إعطاؤه الرتبة** المحدّدة (رتبة الإدارة)
5. كل الرسائل والخانات **قابلة للتعديل** من اللوحة (تبويب 📝 تقديم الإدارة) أو من ديسكورد.

| الأمر | الوظيفة |
|---|---|
| `/tickets applychannel` | قناة مراجعة الطلبات |
| `/tickets applycategory` | قسم تكتات الإدارة (مكان نقل المقبولين) |
| `/tickets applyrole` | رتبة تُعطى عند القبول |
| `/tickets applyping` | رتبة تُنبَّه عند وصول طلب جديد |
| `/tickets applytoggle` | تفعيل/تعطيل الاستمارة |
| `/tickets application` | عرض الإعدادات والخانات الحالية |

### 📈 المستويات

• `/leveling rank` و `/leveling leaderboard` • كولداون واستثناء قنوات/رتب.

### ⚡ بلا كولداون + عقوبات بالآيدي
- **الكولداون مشيل من كل الأوامر**: سلاش + الأوامر بلا بريفيكست — بلا أي انتظار بين أمر وأمر.
- **`/ban`** في خيارين للهدف: **العضو** (منشن) أو **آيدي** — والعضو داخل السيرفر أو برّا (حظر بالآيدي مباشرة).
- **`/kick`** بالمنشن أو بخيار **آيدي**، ولو العضو برّا السيرفر يوضّح إن ديسكورد ما يسمح بالطرد ويرشدك لـ `/ban`.
- **`/unban`** يقبل آيدي · منشن `<@id>` · `<@!id>` · الاسم الكامل · اسم المستخدم.
- أوامر الشات (بلا بريفيكست) تقبل آيدي العضو الرقمي كمان، مو بس المنشن: `ban 123456789012345678 سبب`.

### 💬 شكل الردود — إنجليزي بخط مزخرف (𝑪𝒉𝒂𝒕)
كل ردود البوت في ديسكورد بالإنجليزية وبخط **Mathematical Bold Italic** مثل `𝑪𝒉𝒂𝒕`:
- تشمل الأوامر · الترحيب · السجلات · التذاكر · الحماية · رسائل الخاص.
- محفوظ كما هو: المنشنات `<@123>` · الروابط · الأكواد بين \` \` · الإيموجيات الخارجية · التواريخ · أوامر السلاش `/tickets` · المدد `10m`.
- الأزرار والقوائم تُترجم بخط عادي حتى تبقى واضحة.
- التحكم: لوحة التحكم ← الإعدادات العامة ← «شكل الردود» (ردود بالإنجليزية · الخط المزخرف)، مع معاينة فورية قبل/بعد.
- أي نص غير موجود في القاموس يبقى كما هو — ما يتكسر ولا شي.

## 🔧 إعداد ديسكورد (Developer Portal)

1. افتح [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. من **Bot**:
   - انسخ **Token** → ضعه في `DISCORD_TOKEN`.
   - فعّل الـ Intents التالية (إلزامية):
     - ✅ **SERVER MEMBERS INTENT**
     - ✅ **MESSAGE CONTENT INTENT**
   - انسخ **Application ID** → `CLIENT_ID`.
3. من **OAuth2 → General**: انسخ **Client Secret** → `CLIENT_SECRET`.
   وأضف **Redirect URL**: `http://localhost:3000/auth/callback`
   (أو `https://نطاقك.com/auth/callback` عند النشر).
4. **دعوة البوت:** OAuth2 → URL Generator:
   - Scopes: `bot` + `applications.commands`
   - Permissions الموصى بها: `Administrator` (أو الصلاحيات المطلوبة فقط:
     Manage Server, Ban, Kick, Moderate Members, Manage Messages, Manage Channels,
     Manage Roles, Manage Nicknames, View Audit Log, Send Messages, Embed Links, Attach Files, Read Message History)
5. **مهم:** اجعل رتبة البوت **أعلى** من الرتب التي سيديرها في السيرفر.

## 🌐 إعداد لوحة التحكم (OAuth2)

لاستخدام تسجيل الدخول الحقيقي:

1. تأكد من `CLIENT_ID` و `CLIENT_SECRET` في `.env`.
2. اضبط `DASHBOARD_URL` ليطابق رابط العودة **حرفيًا** (مثال: `http://localhost:3000`).
3. غيّر `SESSION_SECRET` إلى نص طويل عشوائي:
   ```bash
   node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
   ```
4. شغّل `npm start` وافتح `http://localhost:3000`.

**من يستطيع الدخول؟** فقط من يملك صلاحية **إدارة السيرفر** أو **Admin** في سيرفر مُضاف فيه البوت.

> ⚠️ عند النشر على الإنترنت: شغّل اللوحة خلف **HTTPS** واجعل `cookie.secure = true`
> في `src/web/server.js`.

### 🔐 تأكيد الدخول + الرول المطلوب
الموقع **ما يفتحه إلا من سجّل دخوله بحساب Discord** (`LOGIN_REQUIRED=true`)، وبعد الدخول لازم يكون عنده الرول المطلوب.
- **الخطوة ١ — تأكيد الدخول:** أي زائر يُحوَّل إلى `/auth/login` (تسجيل Discord)، ثم يرجع لنفس الصفحة التي طلبها.
- **الخطوة ٢ — الرول:** يُفحص الرول `REQUIRED_ROLE_ID` (افتراضيًا `1549364852433354792`) عند العضو داخل سيرفرات البوت.
  - يملكه → يفتح الموقع كامل (قراءة + تعديل).
  - ما يملكه → صفحة **«الوصول مقيّد»** تشرح الخطوات (ادخل السيرفر • اطلب الرول • أعد الفحص) مع أزرار إعادة الفحص والدخول بحساب آخر.
  - البوت متوقف → رسالة واضحة أن التحقق متعذّر حتى يعود البوت.
- **على مستوى الـAPI:** قراءة/كتابة بدون رول → `403 role_required` برسالة عربية. بدون تسجيل → `401`.
- **الكاش:** نتيجة الفحص تُحفظ في الجلسة 5 دقائق (`ROLE_CACHE_SECONDS`) لتقليل الطلبات على ديسكورد.
- **التحكم:** `REQUIRED_ROLE_ID=` فارغًا يعني قبول أي عضو مسجّل.

### 🔄 المزامنة الحقيقية — معلومات سيرفرك في الموقع
الموقع يزامن معلومات سيرفرك الفعلية من ديسكورد ويحفظها، فلا يعرض بيانات وهمية:

| ما يُزامَن | التفاصيل |
|---|---|
| السيرفر | الاسم • الأيقونة • عدد الأعضاء • المالك • تاريخ الإنشاء • مستوى البوستات |
| القنوات | كل القنوات النصية والصوتية والأقسام (تُستخدم في كل القوائم المنسدلة باللوحة) |
| الرتب | الأسماء والألوان والترتيب (تُستخدم في الرتب التلقائية والمكافآت والصلاحيات) |
| الإيموجيات | إيموجيات السيرفر لعناصر التفاعل التلقائي |

**كيف تشتغل:**
- عند تشغيل البوت: مزامنة فورية، ثم **كل 5 دقائق** (`SYNC_INTERVAL_SECONDS`)، وأيضًا فور أي تغيير (سيرفر/قناة/رتبة) — واللوحة تحدّث نفسها **لحظيًا** عبر بث حيّ (SSE) بدون تحديث الصفحة.
- البوت متوقّف؟ المزامنة تعمل عبر واجهة ديسكورد بالتوكن، وإن تعذّر ذلك يعرض الموقع **آخر لقطة محفوظة** مع وقتها («آخر مزامنة: قبل …»).
- زر **«مزامنة الآن»** موجود في قائمة السيرفرات وفي كل صفحة إعداد + حالة المزامنة ظاهرة في `/api/sync/status`.
- بمجرد وضع `DISCORD_TOKEN` حقيقي في `.env` تتوقّف بيانات العرض تلقائيًا (وتُحذف) وتصير الصفحات تعرض سيرفراتك الحقيقية فقط.
- كل حفظ من الموقع يطبّقه البوت مباشرة (نفس قاعدة البيانات) — ترحيب، حماية، سجلات، تذاكر، مستويات… بدون أي خطوة إضافية.

### 🔗 أمر /help يفتح الموقع فعلًا
عند إرسال `/help` يظهر زر **«افتح الموقع»** وزر **«لوحة التحكم»** — روابط مباشرة تفتح الموقع في المتصفح (زر Link في ديسكورد)، وتظهر كذلك في تفاصيل أي أمر (`/help الأمر:ban`) وفي التذييل.
الرابط يُحدَّد تلقائيًا بالترتيب:

1. `DASHBOARD_URL` إن كان مضبوطًا في `.env` (اختيارك أنت).
2. نطاق منصات النشر: Railway (`RAILWAY_PUBLIC_DOMAIN`) • Render • Fly • Vercel • `PUBLIC_URL`.
3. رابط بيئة المعاينة الحالي، وإن كان `DASHBOARD_URL` رابط معاينة قديمًا من جلسة سابقة يُصحَّح تلقائيًا (روابط المعاينة تتغيّر كل جلسة).
4. `http://localhost:3000` كحل أخير.

**مهم:** رابط `localhost` يفتح فقط على الجهاز الذي يشغّل المشروع، ولازم يكون المشروع شغّالًا وقت الضغط على الزر. إذا كان الرابط محليًا يظهر في `/help` تنبيه بذلك بدل كلام مضلّل.
وللتأكد بسرعة:

```bash
npm run check:site     # يفحص الرابط المحلي والعام ويقول لك سبب المشكلة بالعربي
```

### 🌍 الوصول العام (اختياري — معطّل افتراضيًا الآن)
الموقع مفتوح للجميع للقراءة: أي زائر يفتح الصفحة الرئيسية، ويشاهد قائمة السيرفرات، ويتصفّح إعدادات أي سيرفر مُدرَج فيه البوت — **بدون تسجيل دخول**.
- **القراءة:** متاحة للجميع (GET) عند `PUBLIC_ACCESS=true` (الافتراضي).
- **التعديل:** يحتاج تسجيل دخول بحساب Discord — نقاط الكتابة في الـAPI محميّة بـ401، وتظهر للزائر شارة «عرض عام» مع زر تسجيل الدخول بدل شريط الحفظ.
- لإغلاق الموقع تمامًا: `PUBLIC_ACCESS=false` → ما يفتحه إلا المسجّلون.

### 📱 يتكيّف مع أي شاشة ومع الجهاز نفسه
- **نقاط تكيّف متعدّدة:** جوال صغير (≤400px) • جوال (≤620px) • تابلت (≤1024px) • شاشة كبيرة (≥1500px) + وضع الجوال الأفقي + أنماط الطباعة.
- **الشريط الجانبي في اللوحة** يتحوّل إلى شريط أفقي قابل للسحب على الجوال، والبطاقات تصير عمودًا واحدًا، والجداول تُسحب أفقيًا.
- **الجهاز نفسه:** السمة تتبع إعداد الجهاز (ليلي/نهاري) تلقائيًا إن لم تختر سمة، والزر صار ثلاث حالات: حسب الجهاز ← نهاري ← ليلي.
- **تفاصيل الجوال:** `viewport-fit=cover` + احترام الحواف الآمنة (نتشة آيفون)، وخط الإدخال 16px لمنع تكبير iOS، وأهداف لمس أكبر (40px+)، وإلغاء تأثيرات التحويم على شاشات اللمس، واحترام «تقليل الحركة».
- **قابل للتثبيت كتطبيق:** أيقونة + مانيفست + وسوم آيفون (`apple-mobile-web-app-capable`).

## 🔓 تشغيل الموقع بدون وضع المعاينة (حقيقي 100%)
الموقع يعمل الآن ببيانات سيرفر افتراضية ليُعرض بدون توكن. لتشغيله بحساب Discord حقيقي:

1. ضع `DISCORD_TOKEN` و`CLIENT_ID` و`CLIENT_SECRET` في `.env`.
2. اجعل `DEMO_MODE=false`.
3. في Developer Portal → OAuth2 → Redirects أضف: `https://نطاقك/auth/callback`.
4. أعد التشغيل: `npm start` — وسيصبح الدخول بتسجيل Discord حقيقي، وتظهر سيرفراتك الحقيقية فقط.

> ملاحظة: قيمة `DASHBOARD_URL` تُستخدم في روابط العودة وفي الـ sitemap، فتأكد أنها نطاقك الحقيقي.

## 🌍 نشْر الموقع — رابط يفتح من أي جهاز (جوال/كمبيوتر)

`localhost` يفتح فقط على الجهاز الذي يشغّل المشروع. لرابط يعمل من أي مكان:

### أ) رابط فوري مؤقت (بلا حساب، ثوانٍ)
```bash
npm run web                 # نافذة أولى: الموقع
npm run link:public         # نافذة ثانية: يطبع رابط https عام
# أو احفظه تلقائيًا في .env ليستخدمه /help:
npm run link:public -- --save
```
- يطبع مثلًا: `https://xxxx-yyyy.trycloudflare.com` — افتحه من الجوال مباشرة.
- **مؤقت**: يعيش ما دام الأمر شغّالًا، ويتغيّر في كل تشغيل.

### ب) رابط دائم (Railway — موصى به)
```bash
npm run deploy:railway      # يثبّت CLI + يسجّل دخولك + ينشئ مشروعًا ويرفعه
```
الملفات جاهزة للنشر مسبقًا: `Dockerfile` • `railway.json` (ويستخدم مسار الصحة **`/healthz`**) • `.dockerignore` • وتشغيل مرن بمتغيّرات `RUN_BOT` / `RUN_WEB`.
في لوحة Railway أضف:
1. **Volume** واربطه بـ `/data` ثم ضع `DATABASE_PATH=/data/neverland.db` — لتبقى بياناتك محفوظة.
2. **Variables**: `DISCORD_TOKEN` • `CLIENT_ID` • `CLIENT_SECRET` • `DEMO_MODE=false` • `RUN_BOT=true` (وبدونها الموقع يشتغل عادي، البوت فقط لا يعمل).
3. **Domain**: أنشئ نطاقًا عامًا، واجعله نفسه في `DASHBOARD_URL` وفي Developer Portal → OAuth2 → Redirects:
   `https://نطاقك/auth/callback`

> للتحقق بعد النشر: `https://نطاقك/healthz` يرجّع `{"ok":true,...}` • و`npm run check:site` يفحص كل شيء محليًا.

| اللوحة تعرض «لم تتم المزامنة بعد» | ضع `DISCORD_TOKEN` صالحًا في `.env` ثم شغّل `npm start`، أو اضغط «مزامنة الآن» بعد الدخول |
| الموقع يعرض «مجتمع Never Land» | هذه بيانات العرض لأن التوكن غير مضبوط بعد — بمجرد إضافة التوكن تُستبدل بسيرفراتك الحقيقية |
| الموقع يفتح عندي بس ما يفتح عند غيري | `localhost` محلي — انشر الموقع (`npm run deploy:railway`) أو افتح نفقًا (`npm run link:public`) ثم اضبط `DASHBOARD_URL` |
